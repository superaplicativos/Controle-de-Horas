# Controle-de-Horas
Sistema serverless e 100% gratuito de controle de aulas, alunos e turmas. Desenvolvido em Next.js 16 + TypeScript + Tailwind CSS, utiliza IndexedDB para persistência local rápida no navegador e exportação/sincronização de backups via arquivo TXT e GitHub API. Conta com dashboard, calendário, calculador automático de valores e estatísticas.
