## ✨ Funcionalidades

### 📊 Dashboard
- 4 KPIs principais: Nº Aulas, Horas, Ganhos e Faltas
- Tendência comparada com o mês anterior (com setas ↑↓)
- 5 gráficos: aulas por dia (barras), presenças vs faltas (pizza), ganhos por semana (linha), top 5 alunos (barras horizontais), horas acumuladas (área)
- Atualização em tempo real após qualquer alteração

### 📅 Calendário visual
- Visão mensal colorida por status (presença, falta, cancelada, agendada)
- Dia atual destacado automaticamente
- Toque no dia para lançar aula
- Cores intuitivas: 🟢 presença | 🔴 falta | 🟡 agendada | ⚫ cancelada

### 📝 Cronograma (planejamento)
- **Separado das aulas dadas!** Planeje o futuro sem poluir o dashboard
- Adicione itens com aluno/turma, data, horário, duração e observação
- Use para se organizar — não afeta os números

### 🎓 Aulas Dadas (registro)
- Formulário completo: aluno, data (default hoje), horário, duração, status, conteúdo
- Cálculo automático de valor baseado nas suas regras
- Filtros por mês, status, busca por nome/conteúdo
- Lista com dia da semana destacado

### 👥 Alunos e Turmas
- Cadastro de alunos VIP (1h, 1,5h ou 2h) e Turma (sempre 2h)
- Marcação de ativo/inativo (inativos ainda aparecem no seletor)
- Turmas agrupam alunos
- Histórico completo

### 📈 Fechamento mensal
- Clique em "Fechar Mês" no fim de cada mês
- Snapshot imutável (não dá pra editar depois)
- Histórico completo de meses anteriores
- Perfeito para declaração de impostos e prestação de contas

### 📱 100% responsivo
- Bottom navigation bar no mobile (estilo app nativo)
- Sidebar fixa no desktop
- Modais abrem como bottom-sheet no celular
- Safe areas do iPhone respeitadas

### ☁️ Sync multi-dispositivo
- Basta fazer login com o mesmo usuário e senha em cada dispositivo
- Dados sincronizados automaticamente via Cloudflare Worker + D1
- Funciona entre celular e computador

### 🔐 Segurança
- Senha validada pelo servidor (Cloudflare Worker) com hash SHA-256 e salt
- Cada professor tem seu painel isolado
- Multi-professor: qualquer um pode se cadastrar

### 💰 Cálculo flexível
- **Presença VIP 1h:** R$ 35,00 (configurável)
- **Presença VIP 1,5h:** R$ 52,50
- **Presença VIP 2h:** R$ 70,00

- **Falta (qualquer tipo):** R$ 35,00 (1h fixa)

## ❓ Perguntas frequentes

**Preciso instalar algo?**
Não. Acesse pelo navegador, em qualquer dispositivo.

**Meus dados ficam salvos onde?**
No seu navegador (IndexedDB) e no banco de dados da Cloudflare (D1), sincronizados quando você faz login. Você pode exportar tudo em .txt a qualquer momento.

**Tem fidelidade?**
Zero. Pague mês a mês. Cancele quando quiser, sem multa.

**E se eu cancelar, perco meus dados?**
Nunca. Exporte tudo em .txt a qualquer momento. Seus dados são seus.
